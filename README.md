# clinical-note-extraction-go

本地临床病历文本的抽取与归一化管线。全部输入（病历文本、术语资源）均在本地构造，
不访问外部服务、不下载模型、不使用真实病历数据。仅使用 Go 标准库。

## 结构

```
internal/segment      分节与句子切分：自由文本 → 带原文位置的结构化片段
internal/terminology  不可变的带版本术语资源 + 并发安全的版本注册表
internal/extract      概念抽取、否定/不确定判定、缩写消歧、结论归并
internal/pipeline     串联以上步骤，保证每份文档整体基于同一术语版本
```

## 分节与切分规则（segment）

- 行首或句子终止符之后出现“已知小节名 + `：`/`:`”视为小节标题，冒号后内容属于该小节；
  多个小节名前缀重叠时取最长匹配。
- 任何小节标题之前的正文归入隐式小节 `_preamble`，并标记 `missing_section_header`，不丢弃。
- 同名小节再次出现时内容完整保留，并标记 `duplicate_section`。
- 句子以 `。！？!?；;` 为终止符；换行**不**终止句子，跨行内容保留在同一片段（含原始换行）。
- 小节或文档末尾缺少终止符的句子保留并标记 `truncated_sentence`。
- 每个片段携带原文字节偏移 `[Start, End)`，`text[Start:End]` 恒等于片段文本。
- `Split` 是纯函数：同一文本重复切分结果完全一致。

## 否定与不确定性判定语义（extract）

- **作用域**：修饰词（否定：无/未见/否认…；不确定：疑似/可能…）只作用于
  **同一分句内、出现在其后的概念**。分句以 `，,、；;：。` 或转折词 `但/但是/然而` 分隔。
  因此“无胸痛，伴发热”中否定只覆盖“胸痛”；“无胸痛但伴发热”中转折词切断作用域，“发热”为肯定。
- 同一作用域内否定与不确定同时存在时，**否定优先**。
- 文档级结论按**确定性优先级**归并同一概念的多次提及：
  `affirmed(3) > negated(2) > uncertain(1) > pending(0)`，不任取其一。
- 每次提及与每条结论都携带 `Rationale`，说明命中的修饰词、分句范围与归并依据。

## 缩写消歧与术语版本（terminology / extract）

- 缩写候选按上下文打分：所在小节命中候选倾向小节 +2，每个共现关键词 +1。
  唯一最高分且得分 > 0 时解析为该候选；**无法唯一判定（并列或全零）时极性为 `pending`（待定）**，
  判定依据中列出全部候选。唯一候选的缩写直接解析。
- 术语资源为不可变 `Dictionary`（含版本号）；`Registry` 以原子指针持有当前版本。
  `Pipeline.Process` 在入口处通过 `Snapshot()` 一次性钉住版本，整份文档的分节、抽取、归并
  都基于同一字典，并发处理期间切换版本不会出现新旧混合的判定。
- 历史版本永久保留在注册表中，可随时 `Switch` 回退；升级或回退不会改变已产出结果
  （结果对象记录 `TermVersion`，且字典不可变）。

## 本地验证

```sh
go build ./...
go test ./...          # 全部单元测试
go test ./... -race    # 含并发路径的竞态检测
go test ./internal/extract/ -v   # 日志中打印原文片段、命中规则与判定依据
```

测试覆盖：修饰词作用域（跨分句、转折词、否定优先）、缩写歧义（小节线索/关键词线索/待定）、
术语版本升级与回退、并发处理中的版本一致性、重复处理结果逐字节一致、
畸形文本（无标题、截断、重复小节、空文本）的可区分失败原因。
